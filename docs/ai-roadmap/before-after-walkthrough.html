Nummoria  /  before & after the 11-week plan

What changes underneath the product

The screens a user sees barely move. What moves is the machinery behind every AI response — from one un-instrumented model call to a measured pipeline where documents become typed data and no number ships unverified.

Before

The system today

Every AI decision — parsing a statement, categorizing a charge, answering a question — funnels through a single completion call with the raw data pasted into the prompt.

After · week 11

The system after the plan

Ingestion turns documents into a typed transaction store. The query path runs an agent that reads from that store and passes every answer through a grounding guard. Eval, tracing and safety wrap the whole thing.

Same question, both systems

“Can I afford a $1,200 trip?”

The difference isn't the wording of the answer — it's whether the number in it can be traced to anything.

The point of all of it

What you can put on the résumé

Before

Built a personal-finance web & mobile app with an AI chat assistant. React, React Native, Node, MongoDB, OpenAI API.

— reads as: wired up an API. No way to tell how well it works.

After

  • Multimodal bank-statement extraction pipeline, confidence-gated cascade, ~95% field-level F1 across 15+ layouts.
  • LLM eval harness (100+ cases, judge + assertions) wired into CI; blocks quality regressions on prompt / model changes.
  • Replaced an LLM categorizer with an embeddings + gradient-boosting model: higher accuracy, ~40× cheaper, sub-10 ms p95.
  • 4-tool financial agent with a deterministic numeric-grounding guard — 0 fabricated figures across a 150-case eval.
  • Pre-inference PII-redaction + prompt-injection defense layer, verified against an adversarial document set.

Diagrams show the target architecture, not current code. All figures (F1, cost multiples, latency, fabrication rate) are targets each phase must measure and report honestly — the defensible claim is the methodology and the before/after, whatever the numbers land at. Pairs with the 11-week phased roadmap.
