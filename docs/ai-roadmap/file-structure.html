Scale

What that adds up to

9
new directories
~90
new files (~40 are data)
~50
load-bearing modules under ai/ & eval/
7
existing files modified
ai/tracing/P0

Wraps every model call — tokens, cost, latency, prompt version — into a queryable store.

ai/extraction/P1

Format detection, per-bank parsers, and the confidence-gated parser→model cascade.

eval/P2

The judge + assertion runner, the golden datasets, and the CI entrypoint that gates merges.

ai/categorization/P3

Serving path for the trained classifier plus per-user personalization; LLM kept for labels.

ai/agent/P4

Planner/executor loop, the four tools, the semantic query layer and retrieval.

ai/grounding/P4

The guard: pulls numbers from output, checks each against an allowlist, retries or strips.

ai/safety/P5

Pre-call PII redaction, prompt-injection scanning of ingested documents, policy checks.

backend/ml/P3

Offline: trains the categorizer, benchmarks it against the LLM, exports the ONNX artifact.

Projected layout, not current code — names and boundaries will shift in implementation. Pairs with the 11-week roadmap and the before/after walkthrough; the plain-text version lives at docs/ai-roadmap/FILE-STRUCTURE.md.
